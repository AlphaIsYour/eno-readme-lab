# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Eno README Lab is an entirely client-side web application running in your browser with no remote database, authentication service, or background server processing.

However, if you discover any security issues (such as XSS vulnerabilities during Markdown rendering or prototype pollution):

1. **Do not create a public issue.**
2. Report the vulnerability privately via GitHub Security Advisories on the repository or email the maintainers directly.
3. Please include detailed steps to reproduce the issue, along with proof of concept if available.

We will acknowledge receipt within 48 hours and work towards a prompt resolution.
